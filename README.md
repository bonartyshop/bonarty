# Bonarty Pin Scheduler — privacy policy

A single static page (`privacy-policy/index.html`), hosted on GitHub Pages so Pinterest's
developer app form has a public privacy-policy URL.

Published at: `https://bonartyshop.github.io/bonarty/privacy-policy/`

To change the policy, edit `privacy-policy/index.html`, commit and push. GitHub Pages
redeploys automatically within a minute or two.
